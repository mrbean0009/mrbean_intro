# Premium Portfolio

Open `index.html` directly or serve the folder with a local web server.

## Customize
- Replace the hero PHOTO placeholder with your own image.
- Update social `href="#"` links.
- Replace project content and testimonials.
- The contact form is a front-end demo; connect it to Formspree, EmailJS, a Discord webhook, or your own backend.
- Weather uses browser Geolocation + Open-Meteo. HTTPS is recommended for deployed sites because browser geolocation generally requires a secure context.
